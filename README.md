# 🤖 Dum AI - My First Python Chatbot

This is my first ever Python project! A simple CLI chatbot that interacts with the user.

### ✨ What it does
- Asks for your name
- Asks where you're from (continent)
- Asks your religion
- Asks your favorite place
- Greets you back with a personal message

### 🧠 What I Learned
- `input()` and `print()`
- Variables (str, int, bool, float)
- `type()` and `isinstance()`
- f-strings

### 💻 How to Run
```bash
python chatbot.py
